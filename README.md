# Read My Text

A single-page web app that reads text aloud, sentence by sentence, using your browser's built-in voices. Paste in some text, press Read, and it highlights each sentence as it's read.

**Try it:** https://durransedward.github.io/read-my-text/

## Usage

Open the link above (or download `index.html` and open it in a browser), paste some text, and press Read.

- Put each paragraph on its own line. Text copied from a PDF usually needs tidying first.
- Click any sentence to read from there.
- Space plays and pauses; the left and right arrow keys move between sentences.
- Your speed and voice are remembered. The text itself is never stored, so closing the tab starts afresh.

**Use Microsoft Edge!** At the time of writing (19 November 2026), Microsoft Edge is the only browser with good in-built natural voices. This app has only been tested in Edge.

Edge's natural voices are online voices: the text being read is sent to Microsoft to turn it into speech.
